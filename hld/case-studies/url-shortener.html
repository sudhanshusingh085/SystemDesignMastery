Design a URL Shortener (TinyURL / bit.ly)

A URL shortener is a service that creates shorter aliases for long URLs. Users are redirected to the original URL when they hit these aliases.

📖 URL (Uniform Resource Locator): The address of a given unique resource on the Web.

Step 1 — Requirements

Functional Requirements

  • Given a long URL, our service should generate a shorter and unique alias of it.
  • When users access a short link, our service should redirect them to the original link.
  • Users should optionally be able to pick a custom short link for their URL.
  • Links can have an expiration time.

Non-functional Requirements

  • The system should be highly available.
  • URL redirection should happen in real-time with minimal latency.
  • Shortened links should not be predictable.
  • Scale: 100M new URLs generated per day.

Capacity Estimation

Assuming 100M URLs per day, and a 10:1 read/write ratio, we have 1B redirections per day.

  • Write QPS: 100M / (24 * 3600) ~ 1160 URLs/s
  • Read QPS: 1B / (24 * 3600) ~ 11,600 URLs/s
  • Storage: 100M * 365 * 10 = 365B records in 10 years. If each record is 500 bytes, total storage = 365B * 500B = 182.5 TB.

Step 3 — Deep Dive

URL Encoding (Base62)

To generate short URLs, we can use Base62 encoding (a-z, A-Z, 0-9). With 7 characters, we can generate 62^7 = ~3.5 trillion unique URLs.

Base62 Encoding

Generates short, alphanumeric strings that are URL-safe.

MD5 Hashing

Can cause hash collisions and results in longer hashes (need truncation).

Database Schema Design

We need a simple schema mapping the short URL (or its ID) to the long URL.

Cache Strategy

Since reads (redirections) are 10x more than writes, we need a cache. A 📖 Cache: A temporary storage area that stores copies of frequently accessed data for faster retrieval. like Redis is perfect here.

Step 4 — Implementation (Java 21)

Java 
import java.util.Optional;
import java.time.Instant;
import java.util.concurrent.ConcurrentHashMap;

// Java 21 Record for immutable data
public record UrlMapping(String shortUrl, String longUrl, Instant expiresAt) {}

// Sealed interface for result handling
public sealed interface UrlResult permits UrlResult.Success, UrlResult.NotFound, UrlResult.Expired {
    record Success(String longUrl) implements UrlResult {}
    record NotFound() implements UrlResult {}
    record Expired() implements UrlResult {}
}

interface UrlRepository {
    void save(UrlMapping mapping);
    Optional<UrlMapping> findByShortUrl(String shortUrl);
}

class InMemoryUrlRepository implements UrlRepository {
    private final ConcurrentHashMap<String, UrlMapping> db = new ConcurrentHashMap<>();
    
    @Override
    public void save(UrlMapping mapping) {
        db.put(mapping.shortUrl(), mapping);
    }
    
    @Override
    public Optional<UrlMapping> findByShortUrl(String shortUrl) {
        return Optional.ofNullable(db.get(shortUrl));
    }
}

class Base62Encoder {
    private static final String ALPHABET = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789";
    private static final int BASE = ALPHABET.length();
    
    public String encode(long id) {
        StringBuilder sb = new StringBuilder();
        while (id > 0) {
            sb.append(ALPHABET.charAt((int)(id % BASE)));
            id /= BASE;
        }
        return sb.reverse().toString();
    }
}

public class UrlShortenerService {
    private final UrlRepository repository;
    private final Base62Encoder encoder;
    private long currentId = 1000000; // Mock ID generator

    public UrlShortenerService(UrlRepository repository, Base62Encoder encoder) {
        this.repository = repository;
        this.encoder = encoder;
    }

    public String shortenUrl(String longUrl) {
        String shortUrl = encoder.encode(currentId++);
        repository.save(new UrlMapping(shortUrl, longUrl, Instant.now().plusSeconds(3600 * 24 * 365))); // 1 year validity
        return shortUrl;
    }

    public UrlResult redirect(String shortUrl) {
        return repository.findByShortUrl(shortUrl)
            .map(mapping -> {
                if (Instant.now().isAfter(mapping.expiresAt())) {
                    return new UrlResult.Expired();
                }
                return (UrlResult) new UrlResult.Success(mapping.longUrl());
            })
            .orElse(new UrlResult.NotFound());
    }
}

Step 5 — Optimization

  • Rate Limiting: Implement rate limiting to prevent abuse.
  • Analytics: Add asynchronous tracking using Kafka or another message queue to track click counts, locations, etc.
  • Geographic Distribution: Deploy in multiple regions to reduce latency globally.
💡 Interview Tip: Always clarify if the system needs to support custom aliases early on, as it changes the DB schema and collision handling logic.
