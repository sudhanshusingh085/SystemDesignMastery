Design a News Feed (Twitter / Instagram)

A news feed is a constantly updating list of content generated by a user's connections or accounts they follow.

📖 Eventual Consistency: A guarantee that, if no new updates are made to a given piece of data, eventually all accesses to that item will return the last updated value.

Step 1 — Requirements

Functional Requirements

  • Users can publish text and media posts.
  • Users can view a personalized feed composed of posts from people they follow.
  • Users can follow/unfollow other users.

Non-functional Requirements

  • Feed generation should be fast (loads in < 500ms).
  • System must handle 200M Daily Active Users.
  • Eventual consistency is acceptable for feed updates.

Step 3 — Deep Dive

Fanout Strategy

Fanout is the process of delivering a post to all followers. We have two main approaches:

Fanout on Write (Push)

Pre-compute the feed during post creation. Fast reads, but slow writes for users with millions of followers (celebrities).

Fanout on Read (Pull)

Compute feed dynamically when user loads the app. Slow reads, but no heavy background processing required.

The Solution: Hybrid Approach. Use Push for normal users, and Pull for celebrities to avoid overloading the system when a celebrity posts.

Step 4 — Implementation (Java 21)

Java 
import java.util.List;
import java.util.ArrayList;

// Java 21 Record for a post
public record Post(String postId, String authorId, String content, long timestamp) {}

interface FanoutStrategy {
    void process(Post post, List<String> followers);
}

class PushFanout implements FanoutStrategy {
    private final FeedCache cache;
    public PushFanout(FeedCache cache) { this.cache = cache; }
    
    @Override
    public void process(Post post, List<String> followers) {
        // Push to all followers' caches
        for (String followerId : followers) {
            cache.addPostToFeed(followerId, post);
        }
    }
}

class PullFanout implements FanoutStrategy {
    @Override
    public void process(Post post, List<String> followers) {
        // Do nothing on write. Feeds are constructed on read.
    }
}

class HybridFanout implements FanoutStrategy {
    private final PushFanout push;
    private final PullFanout pull;
    private static final int CELEBRITY_THRESHOLD = 100_000;

    public HybridFanout(PushFanout push, PullFanout pull) {
        this.push = push;
        this.pull = pull;
    }

    @Override
    public void process(Post post, List<String> followers) {
        if (followers.size() > CELEBRITY_THRESHOLD) {
            pull.process(post, followers);
        } else {
            push.process(post, followers);
        }
    }
}

Step 5 — Optimization

  • Caching Hot Feeds: Store active users' feeds in memory (Redis) to ensure sub-millisecond read times.
  • Sharding: Shard the feed data by User ID.
  • CDN for Media: Serve images and videos from a CDN to reduce load on the primary servers.
