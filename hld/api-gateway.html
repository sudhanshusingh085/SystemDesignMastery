API Gateway

What is an API Gateway?

An API Gateway is a server that acts as the single entry point into an application's backend architecture. It sits between the clients (mobile apps, web browsers) and the internal microservices.

Real-World Analogy: The Receptionist or Bouncer
Imagine a large corporate building with many departments (microservices). When visitors (clients) enter, they don't wander the halls looking for the right office. They go to the Receptionist (API Gateway). The receptionist checks their ID (Authentication), gives them a visitor badge (Authorization), and directs them to the correct floor (Routing). If someone is behaving badly, the bouncer throws them out (Rate Limiting).

Why do we need one?

In a microservices architecture, exposing every individual service directly to the public internet is a nightmare:

  • Clients would have to know the IP address of dozens of services.
  • Every service would have to implement its own authentication and security.
  • It would be impossible to monitor overall traffic centrally.

Core Functions of an API Gateway

  1. Request Routing: Inspects the URL and forwards the request to the appropriate microservice (e.g., /users goes to UserService, /orders goes to OrderService).
  2. Authentication & Authorization: Verifies JWT tokens or API keys before letting the request through.
  3. Rate Limiting: Prevents abuse or DDoS attacks by limiting how many requests a user can make in a given timeframe.
  4. Load Balancing: Distributes incoming requests across multiple instances of a backend service.
  5. Response Transformation: Modifying the data before sending it back (e.g., converting XML to JSON).
  6. Caching: Storing frequent responses at the gateway to reduce load on the backend.
  7. Logging & Monitoring: Providing a centralized place to track all incoming traffic and response times.

Rate Limiting Algorithms

Rate limiting is one of the most important jobs of a gateway. Here are common ways to do it:

  • Token Bucket: A bucket holds tokens. Each request costs one token. Tokens are refilled at a constant rate. Allows short bursts of traffic.
  • Leaky Bucket: Requests go into a queue (bucket) and are processed at a constant fixed rate. Smooths out traffic spikes.
  • Fixed Window Counter: Counts requests in a fixed time window (e.g., 1:00 to 1:01). Prone to spikes at the edges of the windows.
  • Sliding Window Log: Keeps a timestamp of every request. Very accurate, but consumes a lot of memory.
  • Sliding Window Counter: A hybrid that is memory efficient and avoids the edge-spike problem.

Code Example: Mini API Gateway with Token Bucket Rate Limiting

Let's build a mini API Gateway with route dispatching and a thread-safe Token Bucket rate limiter in Java and C#.

import java.time.Instant;
import java.util.HashMap;
import java.util.Map;
import java.util.concurrent.atomic.AtomicInteger;

public class ApiGatewayDemo {

    // --- 1. Rate Limiting Logic ---
    interface RateLimiter {
        boolean isAllowed(String clientId);
    }

    /**
     * A simple Token Bucket Rate Limiter
     */
    static class TokenBucketRateLimiter implements RateLimiter {
        private final int maxTokens;
        private final long refillRateMs;
        private final Map<String, ClientState> clientStates = new HashMap<>();

        record ClientState(AtomicInteger tokens, long lastRefillTime) {}

        public TokenBucketRateLimiter(int maxTokens, long refillRateMs) {
            this.maxTokens = maxTokens;
            this.refillRateMs = refillRateMs;
        }

        @Override
        public synchronized boolean isAllowed(String clientId) {
            long now = Instant.now().toEpochMilli();
            var state = clientStates.computeIfAbsent(clientId, 
                id -> new ClientState(new AtomicInteger(maxTokens), now));

            long timePassed = now - state.lastRefillTime();
            int tokensToAdd = (int) (timePassed / refillRateMs);
            
            if (tokensToAdd > 0) {
                int newTokens = Math.min(maxTokens, state.tokens().get() + tokensToAdd);
                state.tokens().set(newTokens);
                clientStates.put(clientId, new ClientState(state.tokens(), now));
            }

            if (state.tokens().get() > 0) {
                state.tokens().decrementAndGet();
                return true;
            }
            return false;
        }
    }

    // --- 2. Microservice Mock ---
    interface Microservice {
        String handle(String request);
    }
    
    static class UserService implements Microservice {
        public String handle(String request) { return "User Data from backend"; }
    }
    
    static class OrderService implements Microservice {
        public String handle(String request) { return "Order Data from backend"; }
    }

    // --- 3. The API Gateway ---
    static class ApiGateway {
        private final RateLimiter rateLimiter;
        private final Map<String, Microservice> routingTable = new HashMap<>();

        public ApiGateway(RateLimiter rateLimiter) {
            this.rateLimiter = rateLimiter;
            routingTable.put("/users", new UserService());
            routingTable.put("/orders", new OrderService());
        }

        public String routeRequest(String clientId, String path) {
            if (!rateLimiter.isAllowed(clientId)) {
                return "HTTP 429: Too Many Requests (Rate limit exceeded for " + clientId + ")";
            }

            Microservice service = routingTable.get(path);
            if (service != null) {
                return "HTTP 200: " + service.handle(path);
            }
            return "HTTP 404: Route Not Found";
        }
    }

    public static void main(String[] args) throws InterruptedException {
        RateLimiter limiter = new TokenBucketRateLimiter(2, 1000);
        ApiGateway gateway = new ApiGateway(limiter);
        String client = "user_abc_123";

        System.out.println(gateway.routeRequest(client, "/users"));   // Allowed
        System.out.println(gateway.routeRequest(client, "/orders"));  // Allowed
        System.out.println(gateway.routeRequest(client, "/users"));   // Blocked
        
        Thread.sleep(1100); 
        System.out.println(gateway.routeRequest(client, "/users"));   // Allowed again
    }
}
using System.Collections.Concurrent;
using System.Diagnostics;

public interface IRateLimiter
{
    bool IsAllowed(string clientId);
}

public class TokenBucketRateLimiter(int maxTokens, TimeSpan refillInterval) : IRateLimiter
{
    private sealed class ClientState(int tokens, long lastRefillTick)
    {
        public int Tokens = tokens;
        public long LastRefillTick = lastRefillTick;
    }

    private readonly ConcurrentDictionary<string, ClientState> _clientStates = new();
    private readonly long _refillIntervalTicks = refillInterval.Ticks;
    private readonly object _syncRoot = new();

    public bool IsAllowed(string clientId)
    {
        lock (_syncRoot)
        {
            long now = Stopwatch.GetTimestamp();
            var state = _clientStates.GetOrAdd(clientId, _ => new ClientState(maxTokens, now));

            long elapsedTicks = now - state.LastRefillTick;
            int tokensToAdd = (int)(elapsedTicks / _refillIntervalTicks);

            if (tokensToAdd > 0)
            {
                state.Tokens = Math.Min(maxTokens, state.Tokens + tokensToAdd);
                state.LastRefillTick = now;
            }

            if (state.Tokens > 0)
            {
                state.Tokens--;
                return true;
            }

            return false;
        }
    }
}

public interface IMicroservice
{
    string Handle(string request);
}

public class UserService : IMicroservice
{
    public string Handle(string request) => "User Data from backend (.NET 8)";
}

public class OrderService : IMicroservice
{
    public string Handle(string request) => "Order Data from backend (.NET 8)";
}

public class ApiGateway(IRateLimiter rateLimiter)
{
    private readonly Dictionary<string, IMicroservice> _routingTable = new()
    {
        ["/users"] = new UserService(),
        ["/orders"] = new OrderService()
    };

    public string RouteRequest(string clientId, string path)
    {
        if (!rateLimiter.IsAllowed(clientId))
        {
            return $"HTTP 429: Too Many Requests (Rate limit exceeded for {clientId})";
        }

        if (_routingTable.TryGetValue(path, out var service))
        {
            return $"HTTP 200: {service.Handle(path)}";
        }

        return "HTTP 404: Route Not Found";
    }
}

Popular Tools

  • Kong: Highly scalable, open-source API Gateway.
  • AWS API Gateway: Fully managed AWS service.
  • Nginx / HAProxy: Traditional reverse proxies that are often configured to act as API gateways.
Interview Tip: API Gateways can become a single point of failure and a bottleneck. Always mention that the API Gateway itself needs to be horizontally scaled and deployed across multiple Availability Zones.
