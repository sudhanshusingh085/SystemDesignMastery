1. Primary Constructors in C# 12: Classes vs Records

Introduced for records in C# 9, C# 12 extended Primary Constructors to standard classes and structs, radically reducing boilerplate when writing dependency-injected services.

// 1. C# 12 Service using Primary Constructor
public class TradeExecutionService(
    ITradingDbContext db, 
    IMessagePublisher bus, 
    ILogger<TradeExecutionService> logger) : ITradeExecutionService
{
    // 'db', 'bus', and 'logger' are in scope across all methods:
    public async Task ExecuteTradeAsync(TradeRequest request, CancellationToken ct)
    {
        logger.LogInformation("Processing trade for {Symbol}", request.Symbol);
        var order = new Order(request.Symbol, request.Quantity, request.Price);

        db.Orders.Add(order);
        await db.SaveChangesAsync(ct);
        await bus.PublishAsync(new TradeExecutedEvent(order.Id), ct);
    }
}

2. C# 12 Collection Expressions & The Spread Operator (`..`)

Before C# 12, initializing collections required fragmented syntax across different collection types (new int[] { 1, 2 }, new List<int> { 1, 2 }, ImmutableArray.Create(1, 2)). C# 12 introduces a unified, zero-allocation syntax using brackets [...] and the spread operator ..:

// 1. Unified initialization for any collection type:
int[] array = [1, 2, 3];
List<string> list = ["AAPL", "GOOG", "MSFT"];
Span<byte> stackSpan = [0x46, 0x49, 0x58]; // Allocates directly on stack!
ReadOnlySpan<char> charSpan = ['A', 'B', 'C'];

// 2. The Spread Operator (..) for merging collections without LINQ allocations:
int[] lowTier = [10, 20];
int[] midTier = [30, 40];
int[] allTiers = [..lowTier, 25, ..midTier, 50]; // [10, 20, 25, 30, 40, 50]
⚡ Compiler Optimization Under the Hood

When the C# compiler processes [..a, ..b], it checks if a and b expose Length or Count. It sums the lengths upfront, allocates a single array of the exact required size, and executes fast memory block copies (Span.CopyTo) rather than resizing or invoking enumerators!

3. Advanced Pattern Matching Evolution

Pattern matching allows expressive, declarative branching based on data shape, type, and relationships:

public decimal CalculateExecutionFee(Order order, TraderProfile trader) =>
    (order, trader) switch
    {
        // Property pattern with relational conditions
        ({ Notional: > 1_000_000m }, { Tier: TraderTier.VIP }) => 5.00m,

        // Relational and logical 'and' / 'or'
        ({ Notional: >= 100_000m and <= 1_000_000m }, _) => 25.00m,

        // Type pattern matching on sub-classes
        (IcebergOrder { VisibleQty: < 100 }, _) => 50.00m,

        // Default discard fallback
        _ => 100.00m
    };

// List Pattern Matching (C# 11):
public string AnalyzeOrderSequence(int[] quantities) =>
    quantities switch
    {
        [100, 200, 300]                => "Exact ladder detected",
        [var single]                   => $"Single batch order of {single}",
        [var first, .., var last]      => $"Ranged batch starting with {first} and ending with {last}",
        []                             => "Empty sequence",
        _                              => "Unrecognized sequence"
    };

4. Raw String Literals (C# 11) & Newlines

Raw string literals start and end with at least three double quotes ("""). They eliminate escaping for quotes, backslashes, and multiline strings:

// 1. Multiline JSON without escaping quotes or newlines:
string jsonConfig = """
    {
        "TradingEngine": {
            "Symbol": "MSFT",
            "MaxLeverage": 5.0,
            "Enabled": true
        }
    }
    """;

// 2. Interpolated Raw String Literals with double dollar signs ($$):
// Any number of '$' characters dictates how many '{' are required for interpolation!
string ticker = "NVDA";
decimal price = 124.50m;

string payload = $$"""
    {
        "symbol": "{{ticker}}",
        "currentPrice": {{price}},
        "timestamp": "{{DateTime.UtcNow:O}}"
    }
    """;

5. Generic Math & Static Abstract Interface Members (C# 11)

Prior to C# 11, you could not write a generic algorithm that performed basic arithmetic (+, -, *) because operators in C# are static methods and could not be defined on interfaces. C# 11 introduced Static Abstract Members in Interfaces, unlocking Generic Math via INumber<T>:

using System.Numerics;

// Generic algorithm that works identically for int, double, decimal, float, BigInteger!
public static T CalculateTotalVolume<T>(ReadOnlySpan<T> values) 
    where T : INumber<T>
{
    T total = T.Zero;
    foreach (var value in values)
    {
        total += value; // Supported generically across all numeric types!
    }
    return total;
}

// Usage:
decimal[] stockPrices = [182.50m, 184.20m, 181.10m];
decimal totalCost = CalculateTotalVolume<decimal>(stockPrices);

int[] shareCounts = [100, 500, 1000];
int totalShares = CalculateTotalVolume<int>(shareCounts);

6. The Senior Interviewer's Grill Round: Modern C#

🔥 Question 1: What is the difference between 'init' and 'readonly' properties in C#?

Senior Answer: A readonly property with only a getter (get;) can only be initialized inside the class constructor. An init-only setter allows the property to be initialized via object initializers (new Order { Price = 100 }) or with expressions during object instantiation, but forbids any subsequent mutation once construction completes. It provides immutable domain models with the convenience of object initializer syntax.

🔥 Question 2: Why was 'file' scoped type accessibility introduced in C# 11?

Senior Answer: The file modifier restricts the scope and visibility of a top-level type to only the source file in which it is declared. It was designed primarily for Roslyn Source Generators. When code generators synthesize helper types, enum converters, or regex matchers, naming collisions can occur if multiple source generators emit identically named classes (e.g. GeneratedHelper). Declaring them as file class GeneratedHelper guarantees zero naming collisions across the compilation unit.

🔥 Question 3: How does non-destructive mutation work with C# records and 'with' expressions?

Senior Answer: When you invoke original with { Price = 150m }, the compiler executes a synthesized shallow clone constructor (protected Order(Order original)) that copies all fields of the original record into a freshly allocated instance on the heap. Then, it invokes the init setter of the specified property (Price) to overwrite that specific value before returning the new reference. The original record remains 100% immutable and untouched.
