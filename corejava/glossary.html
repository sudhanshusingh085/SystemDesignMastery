Glossary — Financial Tech Terms

A comprehensive dictionary of Java, Architecture, and Finance domain terminology.

Core Java

Autoboxing

The automatic conversion the Java compiler makes between the primitive types and their corresponding object wrapper classes (e.g., int to Integer).

Core Java

Type Erasure

The process where the Java compiler removes all generic type information at compile-time to maintain backward compatibility.

Core Java

Record

A restricted identifier in Java 14+ used to declare an immutable data-carrying class with concise syntax (often used for DTOs like Trade details).

Core Java

Sealed Class

A class/interface that restricts which other classes may extend/implement it, heavily used in domain-driven design for finite states (e.g., TradeStatus).

OOP

Polymorphism

The ability of an object to take on many forms; overriding and overloading methods allowing abstractions (like generic 'Asset') to be treated uniformly.

JVM

Metaspace

Native memory region in JVM (replacing PermGen) that stores class metadata.

JVM

Heap

The runtime data area from which memory for all class instances and arrays is allocated.

JVM

Garbage Collection (GC)

The process of automatically freeing memory on the heap by deleting objects that are no longer reachable (vital to tune in low-latency trading).

Concurrency

Volatile

A keyword ensuring that changes to a variable are always read from main memory, preventing thread-caching issues (crucial in lock-free algorithmic trading variables).

Concurrency

CAS (Compare-And-Swap)

An atomic CPU instruction used in lock-free programming (like AtomicInteger) to update a value only if it hasn't been changed by another thread.

Concurrency

Deadlock

A situation where two or more threads are blocked forever, waiting for each other to release locks.

Concurrency

Virtual Threads

Lightweight threads introduced in Java 21 (Project Loom) mapped dynamically to OS threads, massively scaling blocking I/O without native thread overhead.

Collections

Treeification

The process in Java 8+ HashMaps where bins with too many collisions convert from linked lists (O(n)) to Red-Black trees (O(log n)) to prevent DOS attacks.

Collections

ConcurrentHashMap

A thread-safe hash map implementation that achieves high throughput by using lock striping (or CAS operations in newer Java versions).

Spring

@Transactional

An annotation that wraps a method in a database transaction, rolling back automatically on RuntimeExceptions (essential for money transfers).

Spring

@Qualifier

Used alongside @Autowired to specify exactly which bean to inject when multiple beans of the same type exist.

JPA

N+1 Problem

A severe ORM performance anti-pattern where a query fetches 1 parent entity, and subsequent N queries are fired to fetch its lazy-loaded children.

JPA

Optimistic Locking

A concurrency control strategy using a `@Version` field to prevent lost updates without holding physical database locks.

JPA

Lazy Loading

A design pattern deferring the initialization of an object until it's needed (e.g., fetching a Portfolio's trades only when getTrades() is called).

Kafka

Partition

The base unit of parallelism in Kafka; an ordered, immutable sequence of records within a topic.

Kafka

Consumer Group

A group of consumers cooperating to consume messages from a topic, where each partition is assigned to exactly one consumer in the group.

Kafka

DLQ (Dead Letter Queue)

A specialized queue/topic where unprocessable messages are sent for manual inspection so they don't block the main flow.

Microservices

Saga Pattern

A distributed transaction pattern involving a sequence of local transactions; if one fails, compensating transactions run to undo the previous steps.

Microservices

Circuit Breaker

A pattern (e.g., Resilience4j) that stops network calls to a failing downstream service, returning a fallback response instantly to prevent cascading failures.

SQL

Window Function

Functions like RANK() or ROW_NUMBER() that perform calculations across a set of table rows related to the current row without collapsing them (GROUP BY).

SQL

Isolation Level

Defines the degree to which a transaction must be isolated from the data modifications made by other transactions (Read Committed, Serializable, etc.).

AWS

EC2 (Elastic Compute Cloud)

Raw virtual machines in AWS providing full OS-level control.

AWS

ECS (Elastic Container Service)

AWS's proprietary container orchestration service, often run serverless via AWS Fargate.

AWS

Lambda

Serverless, event-driven compute service that runs code in response to triggers without managing infrastructure.

AWS

VPC (Virtual Private Cloud)

A logically isolated section of the AWS cloud where you launch resources in a virtual network you define.

Finance

FIX Protocol

Financial Information eXchange. The standard electronic communications protocol for real-time exchange of securities transactions.

FIX

Tag 35 (MsgType)

The FIX field defining the type of message (e.g., D = New Order Single, 8 = Execution Report).

FIX

Sequence Number (Tag 34)

An incremental number attached to every FIX message to guarantee message ordering and detect missing packets.

Finance

T+2 Settlement

Trade Date plus 2 business days; the timeframe within which a security transaction must be settled and paid for.

Finance

OMS (Order Management System)

Software used by institutional traders to execute securities orders and track order status.

Finance

ISIN

International Securities Identification Number; a 12-character alphanumeric code that uniquely identifies a specific security.

Finance

Limit Order

An order to buy or sell a stock at a specific price or better, contrary to a Market Order which executes immediately at the current price.

Finance

Reconciliation

The accounting process of ensuring two sets of records (e.g., the broker's ledger and the bank's account) are in agreement.

Finance

Dark Pool

A private financial forum or exchange for trading securities, allowing investors to trade without public exposure until execution.
