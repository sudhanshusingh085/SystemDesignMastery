# System Design Mastery 🏗️

**From Zero to Interview Ready — Java 21**

A complete, beginner-friendly guide to High-Level Design (HLD) and Low-Level Design (LLD) with:
- 📚 **59 pages** covering 24 sections
- ☕ **Java 21 code** throughout (records, sealed classes, virtual threads)
- 📊 **Mermaid.js diagrams** for visual understanding
- 🎯 **Interview strategies** — RADIO framework, requirement gathering, mock interviews
- 🧱 **SOLID & Design Pattern comments** in every case study
- 👶 **Beginner-friendly** — every term explained, no jargon assumed

## 🚀 How to Use

### Online (GitHub Pages)
Just visit the hosted URL!

### Offline
1. Download/clone this repo
2. Open `index.html` in any browser
3. That's it — works fully offline (except Mermaid diagrams need internet)
