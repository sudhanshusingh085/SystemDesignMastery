Networking Basics

To design scalable software systems, you must understand how computers talk to each other. You don't need to be a network engineer, but grasping the fundamentals of networking is essential for any software developer.

What is a Network? What is the Internet?

📖 Network: Two or more computers connected together to share data.
📖 The Internet: The global system of interconnected computer networks. It is the "network of networks."

If you connect two laptops with a cable, you have a network. If you connect millions of routers, servers, and devices globally, you have the Internet.

Addresses and Doors: IP and Ports

If you want to mail a letter, you need a street address. Computers need addresses too.

  • IP Address: (Internet Protocol Address) This is the unique "street address" for a device on the internet. Example: 192.168.1.5 or 142.250.190.46.
  • Port: If the IP address is the apartment building, the Port is the specific apartment number. A single server might run a web server on Port 80, and an email server on Port 25.

DNS: The Phone Book of the Internet

Humans are bad at remembering numbers like 142.250.190.46, but good at remembering names like google.com.

📖 DNS (Domain Name System): A service that translates human-readable domain names into machine-readable IP addresses.

When you type a URL, your computer first asks a DNS server, "Hey, what is the IP address for google.com?" Once it gets the IP, it connects.

HTTP Methods (The Verbs)

When making an HTTP request, you must specify an action using an HTTP Method.

Method What it does Real-World Analogy
GET Retrieve data Reading a book from a library.
POST Create new data Filing a new document in a cabinet.
PUT Update existing data completely Erasing a whiteboard and drawing a new diagram.
DELETE Remove data Shredding a document.

HTTP Status Codes

When the server responds, it includes a status code to quickly summarize what happened.

  • 200 OK - Everything went perfectly.
  • 301 Moved Permanently - The thing you want has moved somewhere else.
  • 400 Bad Request - You formatted your request wrong.
  • 404 Not Found - The thing you asked for doesn't exist.
  • 500 Internal Server Error - The server crashed or had a bug.

REST APIs and JSON

When modern web applications talk to servers, they usually use a REST API.

📖 REST (Representational State Transfer): A set of architectural rules for designing web APIs using standard HTTP methods.

When data is sent back and forth, it needs to be formatted in a way both sides understand. JSON (JavaScript Object Notation) is the standard format used today.

{
  "userId": 101,
  "name": "Alice",
  "role": "Admin"
}

Performance Metrics

In system design, you must understand three critical network metrics:

  • Latency: How long it takes for a message to travel from sender to receiver. (Analogy: How fast a car drives).
  • Bandwidth: The maximum capacity of a network link. (Analogy: How wide the highway is).
  • Throughput: The actual amount of data successfully transmitted per second. (Analogy: How many cars actually arrive at the destination per minute).

Java 21 Code: Handling JSON in a REST-like way

Let's look at how we might parse a request and return a JSON response using Java 21 features.

Java 
/**
 * Demonstrating how a server might handle different HTTP Methods
 * and return JSON data using Java 21 features like Enhanced Switch.
 */
public class RestApiConcept {

    // Record representing our User resource
    public record User(int id, String name, String email) {
        // Simple helper to convert to JSON string (In reality, use Jackson or Gson)
        public String toJson() {
            return """
                {
                  "id": %d,
                  "name": "%s",
                  "email": "%s"
                }
                """.formatted(id, name, email);
        }
    }

    public static class UserController {
        
        public String handleRequest(String httpMethod, String path) {
            // Pattern matching / Enhanced switch in Java 21
            return switch (httpMethod) {
                case "GET" -> {
                    if (path.equals("/users/1")) {
                        User u = new User(1, "Bob", "bob@example.com");
                        yield "HTTP 200 OK\n" + u.toJson();
                    }
                    yield "HTTP 404 Not Found\n{ \"error\": \"User not found\" }";
                }
                case "POST" -> "HTTP 201 Created\n{ \"status\": \"User saved\" }";
                case "DELETE" -> "HTTP 204 No Content";
                default -> "HTTP 405 Method Not Allowed";
            };
        }
    }

    public static void main(String[] args) {
        UserController controller = new UserController();
        
        // Simulating a GET request
        System.out.println("Client sends: GET /users/1");
        System.out.println("Server responds:");
        System.out.println(controller.handleRequest("GET", "/users/1"));
        
        System.out.println("\n------------------\n");
        
        // Simulating a POST request
        System.out.println("Client sends: POST /users");
        System.out.println("Server responds:");
        System.out.println(controller.handleRequest("POST", "/users"));
    }
}
