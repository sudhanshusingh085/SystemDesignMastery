Design an ATM Machine

Scenario: You are asked to design the Low-Level Design (LLD) for an Automated Teller Machine (ATM) that allows users to withdraw cash, deposit money, check their balance, and transfer funds.

1. What is an ATM Machine System?

An ATM system involves a machine that interacts with a central bank system. Users insert cards, authenticate via PIN, select a transaction, and receive cash or receipts.

📖 State Machine: A system that can be in exactly one of a finite number of states at any given time. The ATM is a classic example, as it moves from Idle -> Authenticating -> Selecting -> Processing -> Dispensing.

2. What problem does it solve?

It provides a standardized, secure way to process banking transactions physically, without human tellers. The challenge is ensuring security, correct state transitions, and precise cash dispensing (handling different denominations).

3. How does it work?

4. Java 21 Code Implementation

Java 

import java.util.*;
import java.time.LocalDateTime;

// Enum for transaction types
enum TransactionType { WITHDRAW, DEPOSIT, BALANCE_CHECK, TRANSFER }
enum Denomination { HUNDRED(100), FIVE_HUNDRED(500), THOUSAND(1000), TWO_THOUSAND(2000); 
    final int value;
    Denomination(int value) { this.value = value; }
}

// Data Records
record Card(String cardNumber, String pin, String bankCode) {}
record Cash(Map<Denomination, Integer> notes) {}
record Receipt(TransactionType type, double amount, LocalDateTime time, String cardNumber) {}

// SOLID: DIP (Dependency Inversion Principle) — depend on abstractions, not concretions
interface BankService {
    boolean verifyPin(Card card, String pin);
    double checkBalance(Card card);
    boolean debit(Card card, double amount);
    boolean credit(Card card, double amount);
}

class BankServiceImpl implements BankService {
    // Dummy implementation for demo
    public boolean verifyPin(Card card, String pin) { return card.pin().equals(pin); }
    public double checkBalance(Card card) { return 10000.0; }
    public boolean debit(Card card, double amount) { return true; }
    public boolean credit(Card card, double amount) { return true; }
}

// SOLID: DIP — CashDispenser abstraction
interface CashDispenser {
    boolean dispense(int amount);
}

// Design Pattern: Chain of Responsibility (implicit here with greedy approach)
class GreedyCashDispenser implements CashDispenser {
    // SOLID: Single Responsibility — this class only handles dispensing cash logic
    @Override
    public boolean dispense(int amount) {
        System.out.println("Dispensing " + amount + " using greedy algorithm...");
        return true;
    }
}

// Design Pattern: State — encapsulated states
sealed interface AtmState permits IdleState, AuthenticatingState, SelectingTransactionState, ProcessingState, DispensingState {
    void handle(AtmMachine atm);
}

// SOLID: Single Responsibility — each state handles only its own logic
final class IdleState implements AtmState {
    @Override
    public void handle(AtmMachine atm) {
        System.out.println("Welcome. Please insert your card.");
        atm.setState(new AuthenticatingState());
    }
}

final class AuthenticatingState implements AtmState {
    @Override
    public void handle(AtmMachine atm) {
        System.out.println("Authenticating card...");
        // In real system, take input. Hardcoding for demo.
        if (atm.getBankService().verifyPin(atm.getCurrentCard(), atm.getCurrentCard().pin())) {
            atm.setState(new SelectingTransactionState());
        } else {
            System.out.println("Invalid PIN.");
            atm.setState(new IdleState());
        }
    }
}

final class SelectingTransactionState implements AtmState {
    @Override
    public void handle(AtmMachine atm) {
        System.out.println("Select transaction: WITHDRAW, DEPOSIT, BALANCE_CHECK...");
        atm.setTransactionType(TransactionType.WITHDRAW); // Mock selection
        atm.setAmount(500); // Mock amount
        atm.setState(new ProcessingState());
    }
}

final class ProcessingState implements AtmState {
    @Override
    public void handle(AtmMachine atm) {
        System.out.println("Processing transaction...");
        if (atm.getTransactionType() == TransactionType.WITHDRAW) {
            if (atm.getBankService().debit(atm.getCurrentCard(), atm.getAmount())) {
                atm.setState(new DispensingState());
            } else {
                atm.setState(new IdleState());
            }
        }
    }
}

final class DispensingState implements AtmState {
    @Override
    public void handle(AtmMachine atm) {
        if (atm.getCashDispenser().dispense((int)atm.getAmount())) {
            System.out.println("Please take your cash.");
            Receipt r = new Receipt(atm.getTransactionType(), atm.getAmount(), LocalDateTime.now(), atm.getCurrentCard().cardNumber());
            System.out.println("Receipt printed: " + r);
        }
        atm.setState(new IdleState());
    }
}

// Design Pattern: Context for State Pattern
class AtmMachine {
    // OOP: Composition — AtmMachine cannot exist without states and services
    private AtmState currentState;
    private final BankService bankService;
    private final CashDispenser cashDispenser;
    
    private Card currentCard;
    private TransactionType transactionType;
    private double amount;

    public AtmMachine(BankService bankService, CashDispenser cashDispenser) {
        this.bankService = bankService;
        this.cashDispenser = cashDispenser;
        this.currentState = new IdleState();
    }

    public void insertCard(Card card) {
        this.currentCard = card;
        runMachine();
    }

    private void runMachine() {
        while (!(currentState instanceof IdleState) || currentCard != null) {
            currentState.handle(this);
            if (currentState instanceof IdleState) {
                currentCard = null; // Reset
                break;
            }
        }
    }

    public void setState(AtmState state) { this.currentState = state; }
    public BankService getBankService() { return bankService; }
    public CashDispenser getCashDispenser() { return cashDispenser; }
    
    public Card getCurrentCard() { return currentCard; }
    public TransactionType getTransactionType() { return transactionType; }
    public void setTransactionType(TransactionType type) { this.transactionType = type; }
    public double getAmount() { return amount; }
    public void setAmount(double amount) { this.amount = amount; }
}

public class Main {
    public static void main(String[] args) {
        BankService bankService = new BankServiceImpl();
        CashDispenser dispenser = new GreedyCashDispenser();
        AtmMachine atm = new AtmMachine(bankService, dispenser);
        
        Card myCard = new Card("1234-5678-9012-3456", "1234", "BANK_1");
        atm.insertCard(myCard);
    }
}

5. Why is this recommended?

Using the State Pattern avoids giant if-else or switch blocks to check what the ATM is currently doing. Each state manages its own transitions, adhering to the Single Responsibility Principle.

Interview Tip: Interviewers love to ask about cash dispensing (Denomination logic). Be prepared to discuss the Greedy Algorithm versus Dynamic Programming for making exact change if specific notes are depleted.
