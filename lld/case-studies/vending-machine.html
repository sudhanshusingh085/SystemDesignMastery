Design a Vending Machine (Masterclass)

Phase 1: Ground-Zero Theory & The Pain Point

A vending machine is a classic Finite State Machine (FSM). In plain English, it behaves differently depending on what state it is in. If you press a button to buy a soda while it's waiting for money, it says "insert coin." If you press the same button after inserting money, it gives you the soda. The disaster happens when we try to implement this logic using massive if/else or switch blocks. The cyclomatic complexity explodes, and eventually, a bug allows someone to get a soda without paying.

Requirement Gathering Dialogue

  • Payment Types: Coins only, or cards as well? (Let's stick to Coins/Cash for algorithmic depth).
  • Inventory Tracking: What happens if an item runs out? (Must refund inserted money).
  • Change Return: Can it return exact change? (The Coin Change algorithm).
  • Cancellation: User can cancel anytime before dispensing to get a full refund.

Phase 2: Domain Entity Modeling & Why State Pattern is Essential

Using if(state == IDLE) { ... } else if (state == HAS_MONEY) { ... } inside every single method (insertCoin, pressButton, dispense) is unmaintainable. When adding a new state (like OUT_OF_SERVICE), you must modify every method, violating the Open/Closed Principle.

  • The State Pattern: By making VendingMachineState an interface, we encapsulate state-specific behavior in separate classes.
  • Why Sealed Interfaces in Java 21? By defining public sealed interface VendingMachineState permits IdleState, HasMoneyState, DispensingState, the compiler guarantees that no unauthorized states can be created, and switch expressions over these states are exhaustive.

Phase 4: Coin Change Algorithm Deep Dive

When returning change, we can use a Greedy Algorithm (pick the largest coin possible first). However, if the coin denominations are non-standard (e.g., 1, 3, 4) and we owe 6, Greedy gives (4, 1, 1) = 3 coins, while Dynamic Programming (DP) gives (3, 3) = 2 coins. For standard US/EU coins, Greedy is mathematically optimal and faster (O(N)). If exact change cannot be made due to empty coin hoppers, the machine must roll back the transaction and refund the original inserted amount.

Phase 5: Production-Grade Java 21 Code

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.locks.ReentrantLock;

// PILLAR 2: Domain entities
enum Coin { 
    QUARTER(25), DIME(10), NICKEL(5), PENNY(1);
    final int value;
    Coin(int value) { this.value = value; }
}

record Product(String id, String name, int priceCents) {}

// Thread-safe Inventory
class Inventory {
    private final Map<Product, Integer> stock = new ConcurrentHashMap<>();
    
    public void addProduct(Product p, int count) { stock.put(p, count); }
    public boolean hasItem(Product p) { return stock.getOrDefault(p, 0) > 0; }
    public void deduct(Product p) { stock.computeIfPresent(p, (k, v) -> v - 1); }
}

// PILLAR 2: Sealed interface for exhaustive pattern matching
sealed interface VendingMachineState permits IdleState, HasMoneyState, DispensingState {
    void insertCoin(VendingMachine context, Coin coin);
    void selectProduct(VendingMachine context, Product product);
    void cancel(VendingMachine context);
    void dispense(VendingMachine context);
}

// State 1: IDLE
record IdleState() implements VendingMachineState {
    public void insertCoin(VendingMachine ctx, Coin coin) {
        ctx.addBalance(coin.value);
        ctx.setState(new HasMoneyState());
        System.out.println("Inserted: " + coin);
    }
    public void selectProduct(VendingMachine ctx, Product product) {
        throw new IllegalStateException("Insert money first!");
    }
    public void cancel(VendingMachine ctx) {
        System.out.println("Nothing to cancel.");
    }
    public void dispense(VendingMachine ctx) {
        throw new IllegalStateException("Cannot dispense in Idle state.");
    }
}

// State 2: HAS_MONEY
record HasMoneyState() implements VendingMachineState {
    public void insertCoin(VendingMachine ctx, Coin coin) {
        ctx.addBalance(coin.value);
        System.out.println("Balance: " + ctx.getBalance());
    }
    public void selectProduct(VendingMachine ctx, Product product) {
        if (!ctx.getInventory().hasItem(product)) {
            System.out.println("Out of stock!");
            return;
        }
        if (ctx.getBalance() >= product.priceCents()) {
            ctx.setSelectedProduct(product);
            ctx.setState(new DispensingState());
            ctx.getState().dispense(ctx); // Auto trigger transition
        } else {
            System.out.println("Insufficient funds!");
        }
    }
    public void cancel(VendingMachine ctx) {
        System.out.println("Refunding: " + ctx.getBalance());
        ctx.clearBalance();
        ctx.setState(new IdleState());
    }
    public void dispense(VendingMachine ctx) {
        throw new IllegalStateException("Select product first!");
    }
}

// State 3: DISPENSING
record DispensingState() implements VendingMachineState {
    public void insertCoin(VendingMachine ctx, Coin coin) {
        throw new IllegalStateException("Please wait, dispensing.");
    }
    public void selectProduct(VendingMachine ctx, Product product) {
        throw new IllegalStateException("Already dispensing.");
    }
    public void cancel(VendingMachine ctx) {
        throw new IllegalStateException("Too late to cancel.");
    }
    public void dispense(VendingMachine ctx) {
        Product p = ctx.getSelectedProduct();
        ctx.getInventory().deduct(p);
        int change = ctx.getBalance() - p.priceCents();
        System.out.println("Dispensed: " + p.name());
        if (change > 0) {
            System.out.println("Change returned: " + change + " cents");
        }
        ctx.clearBalance();
        ctx.setState(new IdleState());
    }
}

// The Context Object
class VendingMachine {
    private VendingMachineState state;
    private final Inventory inventory = new Inventory();
    private int balance = 0;
    private Product selectedProduct = null;
    private final ReentrantLock lock = new ReentrantLock(); // Ensures atomic transactions

    public VendingMachine() {
        this.state = new IdleState();
    }

    public void setState(VendingMachineState state) { this.state = state; }
    public VendingMachineState getState() { return state; }
    
    public void addBalance(int amount) { balance += amount; }
    public int getBalance() { return balance; }
    public void clearBalance() { balance = 0; }
    
    public Inventory getInventory() { return inventory; }
    
    public void setSelectedProduct(Product p) { this.selectedProduct = p; }
    public Product getSelectedProduct() { return selectedProduct; }

    // Synchronized operations
    public void insertCoin(Coin coin) {
        lock.lock();
        try { state.insertCoin(this, coin); } finally { lock.unlock(); }
    }
    public void selectProduct(Product p) {
        lock.lock();
        try { state.selectProduct(this, p); } finally { lock.unlock(); }
    }
}
using System;
using System.Collections.Generic;

public enum Coin { Penny = 1, Nickel = 5, Dime = 10, Quarter = 25 }

public record Item(string Name, int PriceInCents);

public class Inventory
{
    private readonly Dictionary _stock = new();

    public void AddItem(string code, Item item, int count) => _stock[code] = (item, count);

    public Item? GetItem(string code) => _stock.TryGetValue(code, out var entry) ? entry.Item : null;

    public bool IsAvailable(string code) => _stock.TryGetValue(code, out var entry) && entry.Count > 0;

    public void DeductItem(string code)
    {
        if (_stock.TryGetValue(code, out var entry) && entry.Count > 0)
        {
            _stock[code] = (entry.Item, entry.Count - 1);
        }
    }
}

// --- STATE PATTERN ---
public interface IVendingMachineState
{
    void InsertCoin(VendingMachine vm, Coin coin);
    void SelectItem(VendingMachine vm, string code);
    void Dispense(VendingMachine vm);
    void Cancel(VendingMachine vm);
}

public class IdleState : IVendingMachineState
{
    public void InsertCoin(VendingMachine vm, Coin coin)
    {
        vm.CurrentBalance += (int)coin;
        Console.WriteLine($"Inserted {(int)coin}c. Current Balance: {vm.CurrentBalance}c");
        vm.SetState(new HasMoneyState());
    }

    public void SelectItem(VendingMachine vm, string code) => Console.WriteLine("Please insert coins first.");
    public void Dispense(VendingMachine vm) => Console.WriteLine("Please insert coins and choose an item.");
    public void Cancel(VendingMachine vm) => Console.WriteLine("No transaction in progress.");
}

public class HasMoneyState : IVendingMachineState
{
    public void InsertCoin(VendingMachine vm, Coin coin)
    {
        vm.CurrentBalance += (int)coin;
        Console.WriteLine($"Added {(int)coin}c. Total Balance: {vm.CurrentBalance}c");
    }

    public void SelectItem(VendingMachine vm, string code)
    {
        var item = vm.Inventory.GetItem(code);
        if (item == null || !vm.Inventory.IsAvailable(code))
        {
            Console.WriteLine($"Item {code} is out of stock!");
            return;
        }

        if (vm.CurrentBalance < item.PriceInCents)
        {
            Console.WriteLine($"Insufficient balance! {item.Name} costs {item.PriceInCents}c, you have {vm.CurrentBalance}c");
            return;
        }

        vm.SelectedCode = code;
        Console.WriteLine($"Selected {item.Name}. Proceeding to dispense.");
        vm.SetState(new DispensingState());
        vm.Dispense();
    }

    public void Dispense(VendingMachine vm) => Console.WriteLine("Select an item first.");

    public void Cancel(VendingMachine vm)
    {
        Console.WriteLine($"Refunding {vm.CurrentBalance}c. Transaction cancelled.");
        vm.CurrentBalance = 0;
        vm.SetState(new IdleState());
    }
}

public class DispensingState : IVendingMachineState
{
    public void InsertCoin(VendingMachine vm, Coin coin) => Console.WriteLine("Please wait, dispensing item.");
    public void SelectItem(VendingMachine vm, string code) => Console.WriteLine("Currently dispensing.");

    public void Dispense(VendingMachine vm)
    {
        var item = vm.Inventory.GetItem(vm.SelectedCode!)!;
        vm.Inventory.DeductItem(vm.SelectedCode!);
        vm.CurrentBalance -= item.PriceInCents;

        Console.WriteLine($"[DISPENSER] *** CLUNK *** Enjoy your {item.Name}!");

        if (vm.CurrentBalance > 0)
        {
            Console.WriteLine($"[CHANGE] Returning change: {vm.CurrentBalance}c");
            vm.CurrentBalance = 0;
        }

        vm.SelectedCode = null;
        vm.SetState(new IdleState());
    }

    public void Cancel(VendingMachine vm) => Console.WriteLine("Cannot cancel while dispensing!");
}

public class VendingMachine
{
    public Inventory Inventory { get; } = new();
    public int CurrentBalance { get; set; }
    public string? SelectedCode { get; set; }

    private IVendingMachineState _state = new IdleState();

    public void SetState(IVendingMachineState state) => _state = state;
    public void InsertCoin(Coin coin) => _state.InsertCoin(this, coin);
    public void SelectItem(string code) => _state.SelectItem(this, code);
    public void Dispense() => _state.Dispense(this);
    public void Cancel() => _state.Cancel(this);
}

public class Program
{
    public static void Main()
    {
        var vm = new VendingMachine();
        vm.Inventory.AddItem("A1", new Item("Cola", 50), 5);
        vm.Inventory.AddItem("B2", new Item("Chips", 75), 3);

        vm.InsertCoin(Coin.Quarter);
        vm.InsertCoin(Coin.Quarter);
        vm.SelectItem("A1");
    }
}

Phase 6: Trade-offs & The Interviewer's Deep Follow-Up Questions

The Grill Round

Interviewer: "What happens if two users try to purchase the very last soda concurrently over a network?"

Candidate: "In a distributed system, a ConcurrentHashMap isn't enough. We need a Distributed Lock (like Redis Redlock) or Optimistic Concurrency Control using version numbers on the database row to prevent overselling."

Interviewer: "How do you detect hardware jams?"

Candidate: "We introduce a hardware callback mechanism. The dispense() method sends a command to the hardware API and waits for an ACK/NACK. If NACK (jam), we don't transition to IDLE; instead, we transition to a new OUT_OF_SERVICE state and refund the user's balance."

Interviewer: "How would you implement dynamic pricing (e.g., higher prices when it's hot outside)?"

Candidate: "I would use the Decorator or Strategy pattern for pricing. Instead of hardcoding product.priceCents(), we pass the Product through a PricingStrategy.calculatePrice(Product, Context) which considers time of day, weather APIs, or inventory levels."
