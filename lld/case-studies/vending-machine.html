Design a Vending Machine (LLD)

Scenario: Design a vending machine that takes coins/notes, dispenses items, handles stock, gives change, and supports an admin mode.

1. What is a Vending Machine System?

A vending machine is a classic example of a

📖 Finite State Machine (FSM): A system that can only be in one of a finite number of states at any given time, and transitions between them based on events.

2. What problem does it solve?

  • Prevents illegal operations (e.g., dispensing a product without payment).
  • Cleanly manages behavior that drastically changes depending on the system's current situation.

3. How does it work?

4. Java 21 Implementation

We heavily leverage the State Pattern here. Using Java 21's sealed interface allows us to strictly bound the states our machine can enter.

Java 
import java.util.Map;
import java.util.HashMap;

enum Coin { PENNY(1), NICKEL(5), DIME(10), QUARTER(25); 
    final int value;
    Coin(int v) { this.value = v; }
}
enum Note { ONE(100), FIVE(500), TEN(1000); 
    final int value;
    Note(int v) { this.value = v; }
}

record Product(String name, int priceInCents, int quantity) {}

// SOLID: SRP — Inventory just manages stock.
class Inventory {
    private Map items = new HashMap<>();
    public void addProduct(Product p) { items.put(p.name(), p); }
    public boolean isAvailable(String name) {
        return items.containsKey(name) && items.get(name).quantity() > 0;
    }
    public Product getProduct(String name) { return items.get(name); }
    public void decrementStock(String name) {
        Product p = items.get(name);
        items.put(name, new Product(p.name(), p.priceInCents(), p.quantity() - 1));
    }
}

// Design Pattern: STATE — the star of this design!
// Defines exactly what the machine can DO in any state.
sealed interface VendingMachineState permits IdleState, HasMoneyState, DispensingState, MaintenanceState {
    void insertMoney(VendingMachine machine, int amount);
    void selectProduct(VendingMachine machine, String productName);
    void cancel(VendingMachine machine);
    void dispense(VendingMachine machine);
}

class IdleState implements VendingMachineState {
    @Override
    public void insertMoney(VendingMachine machine, int amount) {
        machine.addBalance(amount);
        machine.setState(new HasMoneyState());
    }
    @Override
    public void selectProduct(VendingMachine machine, String productName) {
        System.out.println("Please insert money first.");
    }
    @Override
    public void cancel(VendingMachine machine) {
        System.out.println("Nothing to cancel.");
    }
    @Override
    public void dispense(VendingMachine machine) {
        System.out.println("Payment required.");
    }
}

class HasMoneyState implements VendingMachineState {
    @Override
    public void insertMoney(VendingMachine machine, int amount) {
        machine.addBalance(amount);
    }
    @Override
    public void selectProduct(VendingMachine machine, String productName) {
        Inventory inv = machine.getInventory();
        if (!inv.isAvailable(productName)) {
            System.out.println("Out of stock.");
            return;
        }
        Product p = inv.getProduct(productName);
        if (machine.getBalance() < p.priceInCents()) {
            System.out.println("Insufficient funds. Need " + (p.priceInCents() - machine.getBalance()) + " more.");
        } else {
            machine.setSelectedProduct(p);
            machine.setState(new DispensingState());
            machine.dispense(); // Auto trigger dispensing
        }
    }
    @Override
    public void cancel(VendingMachine machine) {
        System.out.println("Returning balance: " + machine.getBalance());
        machine.clearBalance();
        machine.setState(new IdleState());
    }
    @Override
    public void dispense(VendingMachine machine) {
        System.out.println("Select a product first.");
    }
}

class DispensingState implements VendingMachineState {
    @Override
    public void insertMoney(VendingMachine machine, int amount) { System.out.println("Wait, dispensing..."); }
    @Override
    public void selectProduct(VendingMachine machine, String productName) { System.out.println("Wait, dispensing..."); }
    @Override
    public void cancel(VendingMachine machine) { System.out.println("Too late to cancel."); }
    
    @Override
    public void dispense(VendingMachine machine) {
        Product p = machine.getSelectedProduct();
        machine.getInventory().decrementStock(p.name());
        int change = machine.getBalance() - p.priceInCents();
        System.out.println("Dispensing " + p.name());
        if (change > 0) {
            System.out.println("Returning change: " + change);
        }
        machine.clearBalance();
        machine.setState(new IdleState());
    }
}

class MaintenanceState implements VendingMachineState {
    @Override
    public void insertMoney(VendingMachine m, int a) { System.out.println("Machine in maintenance."); }
    @Override
    public void selectProduct(VendingMachine m, String p) { System.out.println("Machine in maintenance."); }
    @Override
    public void cancel(VendingMachine m) { System.out.println("Machine in maintenance."); }
    @Override
    public void dispense(VendingMachine m) { System.out.println("Machine in maintenance."); }
    
    public void refill(VendingMachine machine, Product p) {
        machine.getInventory().addProduct(p);
    }
    public void finishMaintenance(VendingMachine machine) {
        machine.setState(new IdleState());
    }
}

// SOLID: OCP — VendingMachine delegates behavior to state objects.
// Context class
class VendingMachine {
    private VendingMachineState state;
    private Inventory inventory;
    private int currentBalance;
    private Product selectedProduct;

    public VendingMachine() {
        this.inventory = new Inventory();
        this.state = new IdleState();
        this.currentBalance = 0;
    }

    public void setState(VendingMachineState state) { this.state = state; }
    public Inventory getInventory() { return inventory; }
    public void addBalance(int amt) { currentBalance += amt; }
    public int getBalance() { return currentBalance; }
    public void clearBalance() { currentBalance = 0; }
    public void setSelectedProduct(Product p) { this.selectedProduct = p; }
    public Product getSelectedProduct() { return selectedProduct; }

    // Delegation to state
    public void insertCoin(Coin c) { state.insertMoney(this, c.value); }
    public void insertNote(Note n) { state.insertMoney(this, n.value); }
    public void selectProduct(String name) { state.selectProduct(this, name); }
    public void cancel() { state.cancel(this); }
    public void dispense() { state.dispense(this); }
}

public class Main {
    public static void main(String[] args) {
        VendingMachine vm = new VendingMachine();
        vm.getInventory().addProduct(new Product("Soda", 150, 10)); // $1.50
        
        vm.insertNote(Note.ONE);
        vm.insertCoin(Coin.QUARTER);
        vm.insertCoin(Coin.QUARTER); // Total 150
        
        vm.selectProduct("Soda"); // Should dispense successfully
    }
}

5. Why is it recommended / When to use it?

Using the State pattern completely eliminates massive `if-else` blocks or `switch` statements scattered across the codebase. It ensures that behaviors isolated to a specific state (like returning change while dispensing) cannot be accidentally invoked in another state.

Interview Tip: The State pattern is arguably the most common answer expected for any Vending Machine or ATM interview question. If you write massive if-else logic here, it is a big red flag for interviewers.
